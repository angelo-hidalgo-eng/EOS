## 05-09-2026 — Inicio del proyecto

El proyecto se inicia como parte del desarrollo e implementación del
Engineering Operating System (EOS).

La motivación inmediata es la capacidad limitada del SSD actual de 120 GB
utilizado por el laptop. EOS está siendo desarrollado para soportar proyectos
de ingeniería con diferentes horizontes temporales, incluyendo proyectos de
corto, mediano y largo plazo. Por lo tanto, la capacidad de almacenamiento
disponible comienza a ser una limitación para el desarrollo del sistema.

Se dispone de un segundo SSD de 500 GB, utilizado anteriormente en el mismo
laptop y que contiene una instalación funcional de Windows 11 Pro.

La configuración inicial conocida es:

    SSD A (120 GB) → Linux Mint 22.3 Cinnamon
    SSD B (500 GB) → Windows 11 Pro

El estado objetivo definido para el proyecto es:

    SSD A (120 GB) → Windows 11 Pro
    SSD B (500 GB) → Linux Mint 22.3 Cinnamon

Ambos sistemas operativos deben conservarse.

En esta etapa no se ha modificado ninguno de los dos SSD.
